# 🚀 Guide de Configuration Complet - ImmoCheck DZ\n\n## Étape 1: Préparer l'Environnement\n\n### Windows\n\n1. **Télécharge Node.js:**\n   - Va sur https://nodejs.org/\n   - Clique sur la version LTS (v20.x)\n   - Exécute l'installateur\n   - Accepte tout par défaut\n   - Redémarre ton ordinateur\n\n2. **Vérifie que Node.js est installé:**\n   ```cmd\n   node --version\n   npm --version\n   ```\n\n3. **Télécharge Git:**\n   - Va sur https://git-scm.com/download/win\n   - Exécute l'installateur\n   - Accepte tout par défaut\n   - Redémarre ton terminal\n\n4. **Vérifie que Git est installé:**\n   ```cmd\n   git --version\n   ```\n\n## Étape 2: Clone le Repository\n\n```cmd\ngit clone https://github.com/guerfi-adel-svg/immocheck-dz.git\ncd immocheck-dz\n```\n\n## Étape 3: Installe les Dépendances\n\n### Backend\n```cmd\nnpm install\n```\n\n### Frontend\n```cmd\ncd client\nnpm install\ncd ..\n```\n\n## Étape 4: Lance l'Application\n\n### Option A: Deux Terminaux (Recommandé)\n\n**Terminal 1 - Backend:**\n```cmd\nnpm run dev\n```\nTu devrais voir: `🚀 ImmoCheck DZ Server running on http://localhost:5000`\n\n**Terminal 2 - Frontend:**\n```cmd\ncd client\nnpm start\n```\nL'app va s'ouvrir automatiquement sur http://localhost:3000\n\n### Option B: Un Terminal (Alternative)\n\n```cmd\n# Terminal 1\nnpm run dev\n\n# Dans un autre terminal (Ctrl+Shift+T ou cmd+T)\ncd client && npm start\n```\n\n## Étape 5: Teste l'Application\n\n1. Va sur http://localhost:3000\n2. Remplis le formulaire:\n   - Localisation: \"Alger, Hydra\"\n   - Prix: \"140000000\"\n   - Surface: \"85\"\n3. Clique \"Analyser la Propriété\"\n4. Télécharge le rapport PDF\n\n## Étape 6: Setup Ollama (Optionnel pour Phase 2)\n\n1. **Télécharge Ollama:**\n   - Va sur https://ollama.ai\n   - Clique \"Download\"\n   - Installe pour ton système\n\n2. **Lance Ollama:**\n   ```cmd\n   ollama run llama2\n   ```\n   Cela va télécharger le modèle (~4GB)\n\n3. **Teste que Ollama fonctionne:**\n   ```cmd\n   # Dans un nouveau terminal\n   curl http://localhost:11434/api/tags\n   ```\n\n## Troubleshooting\n\n### \"Node is not recognized\"\n- Redémarre ton ordinateur après installation\n- Ou ajoute Node au PATH manuellement\n\n### \"Port 3000 already in use\"\n```cmd\n# Ferme l'autre process ou change le port\nset PORT=3001 && npm start\n```\n\n### \"Cannot find module 'react'\"\n```cmd\ncd client\nrm -rf node_modules package-lock.json\nnpm install\nnpm start\n```\n\n### \"CORS error\"\n- Assure-toi que le backend tourne sur 5000\n- Assure-toi que le frontend tourne sur 3000\n\n## Prochaines Étapes\n\n- Lis le README.md pour comprendre la structure\n- Explore les fichiers dans `server/` et `client/src/`\n- Modifie le design dans `client/src/App.css`\n- Ajoute des fonctionnalités dans les controllers\n\n---\n\n**Questions?
